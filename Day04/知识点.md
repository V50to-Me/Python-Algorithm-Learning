# Day 04 知识点

## 一、排序

### 1. `sorted()`

```python
nums_sort = sorted(nums)
```

特点：

- 不修改原列表
- 返回一个新的有序列表
- 默认升序

时间复杂度：

```text
O(n log n)
```

---

## 二、线性查找

从头到尾逐个检查：

```python
for i in nums:
    if i == target:
        ...
```

不要求数组有序。

时间复杂度：

```text
O(n)
```

---

## 三、二分查找

### 前提

数组必须有序。

### 闭区间定义

本 Day 统一使用：

```text
[left, right]
```

因此：

```python
left = 0
right = len(nums) - 1

while left <= right:
```

### 中点

```python
mid = (left + right) // 2
```

### 三种情况

```text
nums[mid] < target
→ target 在右边
→ left = mid + 1

nums[mid] > target
→ target 在左边
→ right = mid - 1

nums[mid] == target
→ 找到 target
```

时间复杂度：

```text
O(log n)
```

空间复杂度：

```text
O(1)
```

---

## 四、为什么是 `left <= right`

如果使用闭区间 `[left, right]`：

```text
left == right
```

时仍然存在一个没有检查的元素。

所以必须允许循环继续：

```python
while left <= right:
```

错误地使用：

```python
while left < right:
```

可能漏掉最后一个候选位置。

---

## 五、找第一个 target

普通二分找到 target 后：

```python
answer = mid
right = mid - 1
```

含义：

```text
当前 mid 是候选答案
↓
左边可能还有更早的 target
↓
继续向左
```

---

## 六、找最后一个 target

找到 target 后：

```python
answer = mid
left = mid + 1
```

含义：

```text
当前 mid 是候选答案
↓
右边可能还有更晚的 target
↓
继续向右
```

---

## 七、找第一个满足条件的位置

例如：

```text
找第一个 nums[i] >= target
```

如果：

```python
nums[mid] >= target:
```

那么：

```python
answer = mid
right = mid - 1
```

因为：

- `mid` 可能是答案
- 左边可能还有更早的满足条件的位置

如果：

```python
nums[mid] < target:
```

那么：

```python
left = mid + 1
```

因为 `mid` 以及左边都不满足条件。

---

## 八、`answer = -1` 的意义

当答案可能不存在时：

```python
answer = -1
```

表示：

```text
目前没有找到合法答案
```

例如寻找某个 target：

```text
找到 → answer = 实际下标
没找到 → answer = -1
```

注意：

> `-1` 是状态标记，不一定可以直接参与后续数学计算。

例如统计出现次数时：

```python
right_value - left_value + 1
```

如果两个位置都是 `-1`：

```text
-1 - (-1) + 1 = 1
```

但真实答案应该是 `0`。

所以需要先判断：

```python
if left_value == -1:
    print(0)
```

---

## 九、状态变量初始化位置

错误：

```python
while left <= right:
    answer = -1
```

因为每次循环都会重置答案。

正确：

```python
answer = -1

while left <= right:
    ...
```

原则：

> 状态变量初始化一次，循环中负责更新。

---

## 十、两次二分必须重新初始化

如果需要先找最后一个 target，再找第一个 target：

第一次：

```python
left = 0
right = len(nums) - 1
```

二分结束后：

第二次必须重新：

```python
left = 0
right = len(nums) - 1
```

不能继续使用第一次二分修改过的搜索区间。

---

## 十一、两次边界二分统计频次

对于有序数组：

```text
第一个 target = left_value
最后一个 target = right_value
```

如果存在：

```text
count = right_value - left_value + 1
```

如果不存在：

```text
count = 0
```

复杂度：

```text
每次查询：O(log n)
q 次查询：O(q log n)
```

---

## 十二、排序 + 多次二分

如果原数组无序：

```text
原数组
↓
排序一次
↓
多次二分查询
```

复杂度：

```text
排序：O(n log n)
查询：O(q log n)

总复杂度：
O(n log n + q log n)
```

不要每次查询都重新排序。

---

## 十三、Day04 最重要的二分思维

不要只背：

```python
while left <= right:
```

真正要问：

### 问题 1

`mid` 是否可能是答案？

### 问题 2

如果 `mid` 是答案，左边还有没有可能存在更优答案？

### 问题 3

如果左边还有可能：

```python
right = mid - 1
```

### 问题 4

如果右边还有可能：

```python
left = mid + 1
```

### 问题 5

最终没有答案时，用什么值表示？

通常可以使用：

```python
-1
```

---

## 十四、Day04 易错点

- 二分数组没有排序。
- `while left < right` 导致边界漏检。
- `left/right` 更新时忘记 `+1/-1`。
- 找到一个 target 就 `break`，但题目要求第一个/最后一个。
- `answer` 没初始化导致 `NameError`。
- 在 while 内初始化 answer，导致答案被覆盖。
- 第二次二分没有重置 `left/right`。
- `-1` 直接参与最终计算。
- 把“找 target”与“找第一个满足条件的位置”混为一谈。
- 认为使用二分后总复杂度一定是 `O(log n)`，忽略前面的排序。

---

## Day04 一句话总结

> **二分查找的核心不是“每次取中间值”，而是维护一个不断缩小的候选答案区间，并明确答案边界。**
