## 核心收获

1. 排序题先想清楚"比较规则"，key 返回元组，一次编码所有条件
2. 数字降序取负号；字符串降序用两次排序（先次要规则，后主要规则）
3. 稳定性：key 相同的元素保持原有相对顺序——两次排序的原理
4. 全数字用一次排序（负号），有字符串降序才用两次排序
5. `sorted` 是 O(n log n)；n = 10^5 时 O(n²) 必超时
