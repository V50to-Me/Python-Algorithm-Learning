# Day07 知识点：排序进阶

日期：2026-08-29

## 1. 元组（tuple）

- 小括号包裹、逗号分隔：`p = ("Tom", 85)`
- 用法和 list 几乎一样（下标、遍历），区别：创建后不可修改
- 核心价值：把多个数据**捆绑**成一个单位，排序时永不分离
- 对比字典：dict 键必须唯一，"名字→分数"的映射遇到同名学生会互相覆盖，
  所以排序类题目优先用元组列表

## 2. 元组比较规则：字典序

- `(a, b) < (c, d)`：先比第 0 位；**打平了才比第 1 位**
- 例：`(85, "Tom") < (85, "Alice")` → False（分数打平，比名字，"Alice" < "Tom"）
- 这个规则天然对应"多条件排名"：主条件放第 0 位，次条件放第 1 位，
  条件有几个元组就有几位

## 3. sorted 的 key 参数

- `sorted(列表, key=函数)`：排序前先对每个元素调用一次函数，按**返回值**排序
- `lambda t: 表达式` = 现场写的小函数，`t` 是每个元素
- 例：`key=len` 按长度排；`key=lambda t: t[1]` 按元组第 1 位排

## 4. 降序的三种实现

| 场景 | 方法 |
| --- | --- |
| 某个数字键要降序 | key 里取负号：`-x`（首选） |
| 整个结果都要反过来 | `reverse=True`（会把次要规则一起翻，慎用） |
| 字符串键要降序 | 负号失效 → 两次排序 + 稳定性 |

## 5. 稳定排序与两次排序

- Python 的 sorted 是**稳定**的：key 相同的元素，结果里保持原有相对顺序
- 两次排序实现任意方向组合：
  1. **先**按次要规则排；
  2. **后**按主要规则排（**最后排的说了算**）
- 主要规则打平的元素，保持上一次排好的顺序
- 选择标准：**全数字 → 取负号一次排完；有字符串要降序 → 才用两次排序**

## 6. 竞赛流水线：哈希计数 + 排序

```text
dict 计数 → items() 拿 (键, 次数) → 元组列表 → 多关键字排序 → 输出
```

Day02 的 `get` 计数 + Day07 的排序，是"统计后按要求输出"类题目的固定套路。

## 7. 复杂度底线

- `sorted` 是 O(n log n)
- n = 10^5 时 O(n²) ≈ 10^10 次操作，必超时
- 看到大数据范围先想：排序 / 哈希 / 前缀和 / 双指针，别写双重循环枚举

## 踩坑记录

1. 字符串数字与整数的比较："9" > "10"（按字典序逐字符比）→ 读入数字必须 int()
2. 负号技巧只对数字有效；字符串降序不能取负
3. 两次排序的顺序：次要规则先排，主要规则后排
4. `reverse=True` 是整体反转，不能只反转某一个条件
5. dict 键唯一：可能有重复名字时不能用名字当键
