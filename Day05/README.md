## 1. 普通前缀和

定义：

```text
prefix[i] = nums[0] ~ nums[i-1] 的和
```

区间 `[l, r]`：

```text
prefix[r + 1] - prefix[l]
```

复杂度：

```text
预处理：O(n)
单次查询：O(1)
总复杂度：O(n + q)
空间：O(n)
```

---

## 2. 条件计数前缀和

把条件转化为 0/1：

```text
满足条件 -> 1
不满足 -> 0
```

例如：

```python
if nums[i] % 2 == 0:
    prefix.append(prefix[i] + 1)
else:
    prefix.append(prefix[i])
```

可以解决：

- 区间偶数数量
- 区间 >= 5 数量
- 区间奇数数量
- 区间满足某个简单条件的元素数量

---

## 3. 相邻关系前缀和

统计：

```text
nums[i] > nums[i-1]
```

发生的次数。

这里 prefix 定义不同：

```text
prefix[i] = nums[0] 到 nums[i] 之间发生的上升次数
```

因此查询：

```text
prefix[r] - prefix[l]
```

不能机械套用普通前缀和公式。

---

## 4. 前缀和的核心思想

> 预处理换查询时间。

暴力：

```text
O(nq)
```

前缀和：

```text
O(n + q)
```

所以当 n、q 都很大时，前缀和可以把大量重复计算消掉。

---

## 5. 下标思维

### l / r

```text
l = left
r = right
```

`[l, r]` 是闭区间。

### 不要死记 +1 / -1

先问：

> 这个位置还要不要？

二分：

```python
nums[mid] < target
```

`mid` 不可能是答案：

```python
left = mid + 1
```

前缀和：

```python
prefix[r + 1]
```

是因为需要让 `nums[r]` 被包含进来。

真正重要的是：

> 先定义 prefix[i]，再推导公式。

---

## 6. 前缀和不是万能的

区间求和、区间计数很适合前缀和。

但区间最大值不能简单写成：

```text
prefix[r] - prefix[l]
```

所以看到“区间查询”时，不要条件反射地使用前缀和。
