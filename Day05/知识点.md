# Day05 知识点

## 1. 普通前缀和

定义：

`prefix[i] = nums[0] ~ nums[i-1] 的和`

构造：

```python
prefix = [0]
for i in range(len(nums)):
    prefix.append(prefix[i] + nums[i])
```

闭区间 `[l, r]`：

```python
prefix[r + 1] - prefix[l]
```

不要死背 `r + 1`，要根据定义推导：`prefix[r + 1]` 才包含 `nums[r]`。

---

## 2. 多次区间查询

暴力每次扫描区间：

- 单次最坏 O(n)
- q 次 O(nq)
- 当 q 与 n 同量级时可达 O(n²)

前缀和：

- 预处理 O(n)
- 单次查询 O(1)
- 总计 O(n + q)

核心思想：

> 预处理换查询时间。

---

## 3. 条件计数前缀和

前缀和不只是“求和”。

例如统计偶数：

```python
if nums[i] % 2 == 0:
    prefix.append(prefix[i] + 1)
else:
    prefix.append(prefix[i])
```

本质：

```text
满足条件 -> 1
不满足 -> 0
```

也可以统计：

- >= 5 的数量
- 奇数数量
- 能被 3 整除的数量
- 满足任意简单条件的元素数量

## 4. 相邻关系前缀和

今天的重要变式：

统计 `nums[i] > nums[i-1]` 的次数。

定义：

`prefix[i] = nums[0] 到 nums[i] 之间发生的上升次数`

因此：

```python
for i in range(1, len(nums)):
    if nums[i] > nums[i - 1]:
        prefix.append(prefix[i - 1] + 1)
    else:
        prefix.append(prefix[i - 1])
```

查询 `[l, r]`：

```python
prefix[r] - prefix[l]
```

这里不能机械使用 `prefix[r + 1] - prefix[l]`，因为 prefix 的定义已经改变。

---

## 5. l、r 和下标的理解

```text
l = left = 左边界
r = right = 右边界
```

`[l, r]` 是闭区间，两端都包含。

核心原则：

> 不要背 +1 / -1，先判断这个位置是否还需要。

例如二分：

```python
if nums[mid] < target:
    left = mid + 1
```

因为 `mid` 已经不可能是答案。

```python
if nums[mid] > target:
    right = mid - 1
```

同理，`mid` 不可能是答案。

找第一个 `>= target` 时：

```python
answer = mid
right = mid - 1
```

因为 `mid` 可能是答案，要先保存，再继续向左寻找更优答案。

---

## 6. 前缀和适用范围

适合：

- 区间求和
- 区间计数
- 区间满足条件的元素数量
- 某些可以累计的信息

不应机械用于：

- 区间最大值
- 区间最小值

因为最大值、最小值不能像加法那样通过两个前缀值相减直接消掉前面的部分。

## 7. 今日易错

### 输入

错误：

```python
input.split()
```

正确：

```python
input().split()
```

### 调试输出

提交时删除：

```python
print(prefix)
```

否则可能导致输出格式错误。

### 最重要的易错点

看到：

```python
prefix[...]
```

先问：

> `prefix[i]` 到底表示什么？

再决定查询时是：

```text
prefix[r + 1] - prefix[l]
```

还是：

```text
prefix[r] - prefix[l]
```
