```python

```

```python
range(len(numbers) - 1)
```

- 最长连续偶数段

核心状态：

```text
current
max_length
```

---

### 3. 边界情况

重点学习：

- 全程上升
- 全部不满足条件
- 最后一段一直延续到数组末尾
- `n = 1`
- 条件出现在开头
- 条件出现在结尾

特别理解：

> 如果 `current` 在条件不满足时会被重置，需要注意在重置前保存答案。

同时要注意：

> 如果最后一段一直持续到数组末尾，循环结束后可能还需要再次检查 `current`。

---

### 4. 预处理数组

完成：

```text
left[]
right[]
```

理解：

```text
left[i]
→ 以 i 结尾的连续偶数长度

right[i]
→ 以 i 开始的连续偶数长度
```

通过预处理，将原本可能需要重复扫描的问题优化到：

```text
O(n)
```

### 6. 枚举

学习：

```python
for i in range(n):
    for j in range(i + 1, n):
        ...
```

用于枚举不同位置的二元组合。

理解：

- 避免自己和自己匹配
- 避免重复组合
- 暴力枚举通常为 `O(n²)`

---

### 7. Two Sum / 哈希优化

先完成 `O(n²)` 暴力版本，再使用：

```python
seen = set()
```

将查找配对数字的过程优化到平均 `O(1)`。

核心：

```text
当前数字 x
↓
需要 target - x
↓
去 seen 中查询
↓
存在 → 找到
不存在 → 加入 seen
```

最终时间复杂度：

```text
平均 O(n)
```

空间复杂度：

```text
O(n)
```

## 今日重要收获

### 状态维护

```text
初始化
↓
遍历
↓
更新状态
↓
更新历史最优
```

### 边界意识

不能只验证样例，需要主动检查：

```text
n = 1
全满足
全不满足
开头
结尾
最后一段
没有合法答案
```

### 复杂度意识

开始理解：

```text
O(n²)
↓
数据规模增大后可能不可接受

O(n)
↓
可以处理更大的数据
```

### 哈希优化

第一次将：

```text
暴力枚举 O(n²)
```

优化为：

```text
Set 哈希查询，平均 O(n)
```
