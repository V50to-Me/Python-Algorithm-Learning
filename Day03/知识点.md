# Day 03 知识点

## 一、相邻元素与下标边界

如果需要同时访问：

```python
numbers[i]
numbers[i + 1]
```

那么 `i` 最大只能到 `len(numbers) - 2`。

因此通常使用：

```python
for i in range(len(numbers) - 1):
```

例如：

```python
for i in range(len(numbers) - 1):
    if numbers[i + 1] > numbers[i]:
        ...
```

---

## 二、状态维护

很多算法都可以抽象成：

```text
初始化状态
↓
遍历数据
↓
根据当前元素更新状态
↓
更新历史最优答案
```

例如：

```python
current = 1
max_length = 1

for x in numbers:
    ...
```

其中：

- `current`：当前状态
- `max_length`：到目前为止的历史最优结果

---

## 三、`current` 和 `max_length`

### `current`

表示：

> 当前连续区间的状态或长度。

### `max_length`

表示：

> 到目前为止发现的最长长度。

例如最长连续上升段：

```python
if numbers[i + 1] > numbers[i]:
    current += 1
else:
    current = 1

if current > max_length:
    max_length = current
```

---

## 四、状态重置前保存答案

如果某个条件不满足时会导致：

```python
current = 0
```

那么需要注意：

```text
先保存 current
↓
再重置 current
```

错误顺序：

```python
current = 0

if current > max_length:
    max_length = current
```

这样可能丢失刚刚结束的连续区间。

正确思路：

```python
if current > max_length:
    max_length = current

current = 0
```

---

## 五、循环结束后的最终检查

如果最后一段一直持续到数组末尾，中间可能没有触发“结束条件”。

例如：

```text
2 4 6 8
```

整个过程中都没有遇到奇数。

所以某些算法需要在循环结束后：

```python
if current > max_length:
    max_length = current
```

来处理最后一段。

---

## 六、连续区间问题

不同题目只改变“连续”的判断条件。

### 1. 连续上升

```python
numbers[i + 1] > numbers[i]
```

### 2. 连续相同

```python
numbers[i + 1] == numbers[i]
```

### 3. 连续满足某个条件

例如连续偶数：

```python
x % 2 == 0
```

一个常见的状态维护结构：

```python
current = 0
max_length = 0

for x in numbers:
    if condition:
        current += 1
    else:
        current = 0

    if current > max_length:
        max_length = current
```

如果采用“中断时保存”的写法，还需要处理循环结束后的最后一段。

---

## 七、初始化状态

初始化变量时，必须考虑这个状态的合法取值范围。

### 普通最大值

如果数据可能全部为负数：

```python
max_value = numbers[0]
```

不能随意：

```python
max_value = 0
```

因为 `0` 可能根本不是合法候选值。

例如：

```text
-5 -2 -8
```

正确最大值是：

```text
-2
```

---

### 长度类问题

如果答案允许为 `0`：

```python
max_length = 0
```

是合理的。

例如：

```text
1 3 5 7
```

没有任何连续偶数，因此：

```text
最长连续偶数长度 = 0
```

### 初始化三问法

遇到“最大值/最小值该怎么初始化”时，先问：

1. 这个状态的合法取值范围是什么？
2. 我选择的初始值是不是合法状态？
3. 这个初始值会不会影响最终答案？

---

## 八、`left` / `right` 预处理数组

当一个位置需要快速知道：

- 左边的连续状态
- 右边的连续状态

可以提前预处理两个数组。

### `left[i]`

表示：

> 以 `i` 结尾的连续偶数长度。

例如：

```python
left[i] = left[i - 1] + 1
```

前提是：

```python
numbers[i] % 2 == 0
```

---

### `right[i]`

表示：

> 以 `i` 开始的连续偶数长度。

例如：

```python
right[i] = right[i + 1] + 1
```

前提是：

```python
numbers[i] % 2 == 0
```

---

## 九、正向与反向遍历

### 从左到右

```python
for i in range(n):
```

得到：

```text
0 → 1 → 2 → ... → n-1
```

适合计算：

```text
left[i]
```

---

### 从右到左

```python
for i in range(n - 1, -1, -1):
```

得到：

```text
n-1 → n-2 → ... → 1 → 0
```

适合计算：

```text
right[i]
```

例如：

```python
for i in range(n - 1, -1, -1):
    ...
```

---

## 十、预处理优化

如果每次查询左右连续状态时都重新扫描数组，可能产生：

```text
O(n²)
```

通过提前计算：

```text
left[]
right[]
```

之后就可以在 `O(1)` 时间内查询对应位置的信息。

整体复杂度可以降为：

```text
O(n)
```

即使进行了多次线性遍历：

```text
O(n) + O(n) + O(n)
```

仍然是：

```text
O(n)
```

因为常数项会被忽略。

## 十一、删除一个元素后的区间合并

在“删除一个奇数后的最长连续偶数段”中：

如果删除位置 `i` 的奇数：

```text
2 4 6 3 8 10
      ↑
     删除
```

删除之后：

```text
2 4 6 8 10
```

左右两边的连续偶数会连接起来。

如果 `i` 在中间：

```python
candidate = left[i - 1] + right[i + 1]
```

如果 `i == 0`：

```python
candidate = right[i + 1]
```

如果 `i == n - 1`：

```python
candidate = left[i - 1]
```

## 十二、边界情况

算法题不能只验证题目样例，还需要主动检查：

- `n = 1`
- 全部满足条件
- 全部不满足条件
- 条件出现在开头
- 条件出现在结尾
- 最长区间在数组末尾
- 没有合法候选答案
- 数据全部为负数
- 重复元素

## 十三、模拟

模拟题的核心：

```text
初始化状态
↓
读取操作
↓
逐个执行操作
↓
根据规则修改状态
↓
检查特殊条件
↓
必要时 break
↓
输出最终状态
```

例如得分模拟：

```python
score = 0

for c in s:
    if c == 'A':
        score += 3
    elif c == 'B':
        score -= 2
    elif c == 'C':
        score *= 2
```

---

## 十四、多状态模拟

有些模拟题不只有一个状态。

例如机器人：

```python
x, y = 0, 0
```

每次操作只改变其中一个状态：

```python
if c == 'U':
    y += 1
elif c == 'D':
    y -= 1
elif c == 'L':
    x -= 1
elif c == 'R':
    x += 1
```

核心思想仍然是：

```text
初始化多个状态
↓
遍历操作
↓
根据规则修改状态
```

## 十五、`break`

`break`：

> 立即结束当前这一层循环。

例如：

```python
for c in s:
    ...
    if condition:
        break
```

常用于：

- 找到答案后提前结束
- 达到终止条件后结束模拟
- 不需要继续处理剩余数据

注意：

> `break` 只结束当前所在的循环。

---

## 十六、双重循环枚举

如果需要枚举所有不同位置的二元组合，可以使用：

```python
for i in range(n):
    for j in range(i + 1, n):
        ...
```

它可以避免：

### 1. 自己和自己配对

避免：

```text
(i, i)
```

### 2. 重复组合

避免：

```text
(i, j)
(j, i)
```

例如：

```text
(0,1)
(0,2)
(1,2)
```

每一组只出现一次。

---

## 十七、暴力枚举与时间复杂度

双层嵌套循环通常为：

```text
O(n²)
```

例如：

```python
for i in range(n):
    for j in range(i + 1, n):
        ...
```

当 `n` 较大时，可能无法接受。

因此需要进一步思考：

> 是否可以通过数据结构或算法优化复杂度？

## 十八、Set（集合）

`set` 适合解决：

> 某个元素是否出现过？

创建：

```python
seen = set()
```

添加：

```python
seen.add(x)
```

查询：

```python
if x in seen:
```

集合中的元素会自动去重。

例如：

```python
seen = set()

seen.add(5)
seen.add(5)
seen.add(8)
```

最终：

```python
{5, 8}
```

---

## 十九、哈希查找

`set` 和 `dict` 都基于哈希结构实现，可以进行快速查找。

平均情况下：

```text
x in set
```

的查找复杂度约为：

```text
O(1)
```

因此可以利用哈希结构优化某些 `O(n²)` 问题。

## 二十、Two Sum / 两数之和

题目：

> 判断是否存在两个不同位置的元素，使它们的和等于 `target`。

如果当前元素：

```text
x
```

那么需要寻找：

```text
target - x
```

暴力方法：

```text
O(n²)
```

哈希优化：

```python
seen = set()

for x in numbers:
    if target - x in seen:
        ...
        break

    seen.add(x)
```

核心思想：

```text
当前数字 x
↓
计算需要的配对数字 target - x
↓
去 seen 中查询
↓
存在 → 找到答案
不存在 → 把 x 加入 seen
```

---

## 二十一、为什么必须先查再加入？

正确：

```python
if target - x in seen:
    ...

seen.add(x)
```

不应该直接：

```python
seen.add(x)

if target - x in seen:
    ...
```

原因：

假设：

```text
target = 10
x = 5
```

如果先加入：

```python
seen.add(5)
```

再查询：

```python
if 5 in seen:
```

就可能把当前元素和自己匹配。

而题目要求的是：

> 两个不同位置的元素。

所以应当：

```text
先查询之前出现过的元素
↓
再加入当前元素
```

---

## 二十二、Two Sum 的复杂度

暴力：

```text
时间复杂度：O(n²)
空间复杂度：O(1)
```

哈希优化：

```text
平均时间复杂度：O(n)
空间复杂度：O(n)
```

核心思想：

> 用空间换时间。

---

## 二十三、暴力解与优化解

一个重要的算法思维：

```text
先尝试写出正确的暴力解
↓
分析时间复杂度
↓
判断是否会超时
↓
寻找更高效的数据结构或算法
```

例如 Two Sum：

```text
暴力枚举
O(n²)
↓
使用 set 哈希查找
O(n)
```

不是一开始就追求“最优代码”，而是：

> **先保证正确，再分析瓶颈，再优化。**
