① 遍历
```python
for i in range(len(numbers)):
```
或者：
```python
for x in numbers:
```
② 状态维护
```python
max_value = numbers[0]

for x in numbers:
    if x > max_value:
        max_value = x
```
③ Boolean 状态
```python
found = False
```
发生目标事件：
```python
found = True
```
这叫做状态标记。

④ 提前结束
```python
break
```
找到目标以后不需要继续搜索，就退出循环。

⑤ 记录位置,然后从后面继续：
```python
index = i

for i in range(index + 1, len(numbers)):
```
⑥ 边界情况

永远问自己：
如果没有符合条件的元素怎么办？

例如：
```python
[5, 5, 5, 5]
```
不存在第二大的不同数字。
