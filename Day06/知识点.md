# Day06 知识点

## 1. 双指针

双指针使用两个指针表示两个位置，通过控制指针移动减少无效枚举。

### 相向双指针

```text
L →       ← R
```

常用于有序数组。

核心：

> 根据当前状态判断哪一个指针移动后可以排除不可能的情况。

### 同向双指针

```text
L →        R →
```

常用于连续区间和滑动窗口。

---

# 2. 滑动窗口

窗口：

```text
[L -------- R]
```

基本过程：

```text
R 扩张
↓
维护窗口状态
↓
判断是否满足条件
↓
不满足 → L 收缩
↓
恢复合法
↓
更新答案
```

核心：

> 不重复枚举所有连续区间，而是通过左右边界移动维护当前区间。

---

# 3. `while` 收缩

如果窗口不合法：

```python
while condition:
    ...
```

而不是简单使用 `if`。

因为一次收缩后可能仍然不合法。

---

# 4. 滑动窗口 O(n)

如果：

- R 只向右移动
- L 也只向右移动

那么：

```text
R 最多移动 n 次
L 最多移动 n 次
```

总移动次数：

```text
≤ 2n
```

因此：

```text
O(n)
```

不能因为代码中存在 `for + while` 就直接判断为 O(n²)。

---

# 5. 窗口状态

滑动窗口本质上是在维护某种状态。

例如：

### 区间和

```python
sum
```

### 元素频次

```python
freq
```

### 不同元素数量

```python
len(freq)
```

因此不要死记滑动窗口模板，而应该先问：

> 当前窗口需要维护什么？

---

# 6. 哈希表 + 滑动窗口

适用于：

> 连续区间 + 需要统计元素出现情况 / 不同元素数量等窗口性质。

加入元素：

```python
freq[x] = freq.get(x, 0) + 1
```

删除元素：

```python
freq[x] -= 1

if freq[x] == 0:
    del freq[x]
```

`len(freq)`：

> 当前窗口中不同元素的数量。

---

# 7. 重要操作顺序

删除左端元素：

```python
freq[nums[L]] -= 1

if freq[nums[L]] == 0:
    del freq[nums[L]]

L += 1
```

含义：

```text
元素离开窗口
↓
频次 -1
↓
频次为 0
↓
删除 key
↓
L 前进
```

---

# 8. 题型识别

看到：

> 连续子数组 / 连续子串 + 最长 / 最短 + 某种限制

可以考虑滑动窗口。

进一步判断：

### 如果窗口状态可以随着 L/R 移动增量维护

可以考虑滑动窗口。

### 如果窗口需要记录频次

考虑：

```text
哈希表 + 滑动窗口
```

---

# 9. 正数与滑动窗口

对于：

```text
正数数组 + 区间和限制
```

通常可以利用：

```text
R 右移 → sum 增大
L 右移 → sum 减小
```

形成单调性。

如果存在负数：

```text
R 右移不一定让 sum 增大
```

因此不能直接套用今天的区间和滑动窗口模型。

---

# 10. 常见错误

### 错误 1：漏掉最后一个元素

```python
range(len(nums) - 1)
```

通常会漏掉最后一个下标。

---

### 错误 2：删除元素后才移动 L

正确：

```python
sum -= nums[L]
L += 1
```

而不是：

```python
L += 1
sum -= nums[L]
```

---

### 错误 3：把当前答案当历史最优

```python
length
```

表示当前窗口长度。

```python
max_length
```

表示历史最大长度。

---

### 错误 4：频次为 0 才删除

不能提前判断后再减。

应该：

```python
freq[x] -= 1

if freq[x] == 0:
    del freq[x]
```

---

# 11. 核心思维

最重要：

> **先定义窗口状态，再决定指针什么时候移动。**

不要机械记：

```text
L++
R++
```

应该理解：

```text
L/R 各自代表什么？
为什么移动？
移动后排除了什么？
为什么不会漏掉答案？
```
