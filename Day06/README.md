## 二、双指针

双指针的核心思想：

> 使用两个指针表示两个位置，通过控制指针移动来减少不必要的枚举。

常见形式：

### 1. 相向双指针

```text
L →       ← R
```

两个指针从数组两端向中间移动。

典型应用：

- 有序数组两数之和
- 两端向中间寻找答案
- 根据当前状态决定移动左指针还是右指针

例如有序数组：

```python
nums = [1, 2, 3, 4, 6, 8, 10]
target = 13
```

当前：

```text
nums[L] + nums[R] = 1 + 10 = 11
```

因为数组升序，如果继续选择更大的 `R`，和只会更大，因此此时应该：

```python
L += 1
```

核心不是死记：

```text
大了 R--
小了 L++
```

而是理解：

> 数组有序，所以移动某个指针可以确定排除一部分不可能的情况。

---

## 三、同向双指针

两个指针都从左向右移动：

```text
L →        R →
```

常用于：

- 连续区间
- 连续子数组
- 滑动窗口
- 区间维护

其中最典型的形式就是滑动窗口。

---

# 四、滑动窗口

滑动窗口可以理解为：

```text
[L -------- R]
```

其中：

- `L`：窗口左边界
- `R`：窗口右边界

基本过程：

```text
R 扩张窗口
    ↓
检查窗口是否满足条件
    ↓
如果不满足
    ↓
L 向右移动，缩小窗口
    ↓
恢复合法
    ↓
更新答案
```

核心思想：

> 不重复枚举所有区间，而是通过移动左右边界维护当前区间。

---

## 五、例题：最长和 ≤ 7 的连续子数组

```python
nums = [2, 1, 5, 1, 3, 2]
```

要求：

> 找和 ≤ 7 的最长连续子数组。

代码：

```python
L = 0
max_length = 0
sum = 0

for R in range(len(nums)):
    sum += nums[R]

    while sum > 7:
        sum -= nums[L]
        L += 1

    length = R - L + 1

    if length > max_length:
        max_length = length

print(max_length)
```

输出：

```text
3
```

---

## 六、为什么使用 `while` 而不是 `if`

窗口超限以后：

```text
sum > 7
```

删除一次元素后可能仍然超限。

因此：

```python
while sum > 7:
    ...
```

表示：

> 只要窗口仍然不合法，就继续收缩。

---

# 七、滑动窗口为什么是 O(n)

表面上看：

```python
for R in range(n):
    while ...:
        L += 1
```

似乎是 O(n²)。

实际上不是。

因为：

- `R` 最多向右移动 n 次
- `L` 也最多向右移动 n 次
- `L` 不会向左返回

因此：

```text
总移动次数 ≤ 2n
```

所以：

```text
O(2n) = O(n)
```

这是一种简单的摊还分析思想。

---

# 八、滑动窗口的适用条件

滑动窗口通常依赖某种单调性或可以增量维护的窗口性质。

例如：

```text
正数数组 + 区间和限制
```

加入新的正数：

```text
sum 增大
```

删除左侧正数：

```text
sum 减小
```

因此可以通过：

```text
R 扩张
L 收缩
```

维护合法窗口。

## 负数的注意事项

例如：

```python
nums = [1, -2, 3, 4, -1]
```

加入 `-2` 后，`sum` 反而可能变小。

因此不能直接套用：

```text
sum > target → L++
```

这种依赖正数单调性的滑动窗口。

注意：

> 不是“出现负数就永远不能使用双指针”，而是不能直接套用今天这种基于区间和单调性的窗口模型。

# 九、哈希表 + 滑动窗口

题目：

```python
nums = [1, 2, 1, 2, 3, 1, 2]
```

要求：

> 找最长连续子数组，使其中不同元素数量 ≤ 2。

例如：

```text
[1, 2, 1, 2]
```

其中不同元素：

```text
{1, 2}
```

数量为 2，因此合法。

---

## 为什么需要哈希表？

现在需要知道：

> 当前窗口中有多少种不同元素。

因此需要记录每个元素出现次数：

```python
freq = {}
```

例如：

```text
窗口：[1, 2, 1, 2]

freq = {
    1: 2,
    2: 2
}
```

不同元素数量：

```python
len(freq)
```

结果为：

```text
2
```

因此：

> `len(freq)` 表示不同元素的种类数量，而不是窗口长度。

---

# 十、加入元素

R 向右移动时：

```python
freq[nums[R]] = freq.get(nums[R], 0) + 1
```

含义：

> 当前元素进入窗口，将它的出现次数加 1。

---

# 十一、删除元素

当：

```python
len(freq) > 2
```

说明窗口不合法，需要移动 L。

删除 `nums[L]`：

```python
freq[nums[L]] -= 1

if freq[nums[L]] == 0:
    del freq[nums[L]]

L += 1
```

非常重要：

> 先减少频次，再判断是否为 0，最后删除 key。

---

# 十二、哈希表 + 滑动窗口完整代码

```python
nums = [1, 2, 1, 2, 3, 1, 2]

L = 0
max_length = 0
freq = {}

for R in range(len(nums)):
    freq[nums[R]] = freq.get(nums[R], 0) + 1

    while len(freq) > 2:
        freq[nums[L]] -= 1

        if freq[nums[L]] == 0:
            del freq[nums[L]]

        L += 1

    length = R - L + 1

    if length > max_length:
        max_length = length

print(max_length)
```

输出：

```text
4
```

最长合法窗口：

```text
[1, 2, 1, 2]
```

# 十四、复杂度

普通滑动窗口：

```text
时间：O(n)
空间：O(1)
```

哈希表 + 滑动窗口：

```text
时间：O(n)
空间：O(k)
```

其中 `k` 是窗口中不同元素的数量。

# 十五、今日踩坑记录

### 1. 循环范围漏掉最后一个元素

错误：

```python
for R in range(len(nums) - 1):
```

正确：

```python
for R in range(len(nums)):
```

---

### 2. 初始化 `sum` 后又重复加入第一个元素

如果：

```python
sum = nums[0]
```

就不能让 `R = 0` 时再次加入 `nums[0]`。

更清晰的写法：

```python
sum = 0

for R in range(len(nums)):
    sum += nums[R]
```

---

### 3. 删除元素时顺序错误

错误：

```python
L += 1
sum -= nums[L]
```

正确：

```python
sum -= nums[L]
L += 1
```

含义：

> 先删除当前 L 指向的元素，再移动 L。

---

### 4. 当前长度与历史最大长度混淆

当前窗口：

```python
length
```

历史最优：

```python
max_length
```

最后应该：

```python
print(max_length)
```

而不是：

```python
print(length)
```

---

### 5. `freq` 频次为 0 时才删除 key

正确：

```python
freq[x] -= 1

if freq[x] == 0:
    del freq[x]
```

这样：

```python
len(freq)
```

才能准确表示当前窗口中的不同元素数量。
