## 今日遇到的问题

1. 最大值初始化不能随便设置
2. 条件最大值需要处理“没有符合条件的元素”
3. 字典第一次出现 key 时需要初始化
4. 字符串数字和整数不是同一种类型

## 核心算法思想

### 1. 累加器

total += x

### 2. 计数器

count += 1

### 3. 条件最大值

先找到第一个合法值作为初始值，
之后再不断比较和更新。

### 4. 字典频次统计

第一次出现 → 初始化
再次出现 → +1

### 5. 时间复杂度

顺序执行：相加
嵌套执行：相乘

O(n) 通常优于 O(n²)
