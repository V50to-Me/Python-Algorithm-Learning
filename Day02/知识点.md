# Day 02 知识点

## 一、输入与数据处理

### 1. input()

```python
s = input()
```
 input() 接收用户输入，返回值默认是字符串 str。

例如输入：
```txt
10 20 30
```
得到的是：
```python
"10 20 30"
```

### 2. split()

```python
input().split()
```
按照空白字符对字符串进行分割。

例如：
```python
s = "10 20 30"
print(s.split())
```
得到：
```Python
["10", "20", "30"]
```
注意：分割之后得到的仍然是字符串。

### 3. map()

```python
map(int, input().split())
```
将 split() 得到的每个字符串转换成 int。

例如：
```Python
input().split()
```
得到：
```Python
["10", "20", "30"]
```
经过：
```python
map(int, input().split())
```
相当于：
```txt
10
20
30
```
### 4. list()

如果希望得到一个真正的列表：
```Python
numbers = list(map(int, input().split()))
```
例如输入：
```txt
10 20 30
```
得到：
```Python
numbers = [10, 20, 30]
```
这是算法竞赛中非常常见的输入方式。

## 二、序列解包

例如：
```Python
a, b = [10, 20]
```
执行后：
```Python
a = 10
b = 20
```
也可以结合输入：
```Python
a, b = map(int, input().split())
```
如果输入：
```txt
10 20
```
那么：
```Python
a = 10
b = 20
```
**注意**

左右两边的元素数量必须对应。

例如：
```Python
a, b = [1, 2, 3]
```
会报错，因为左边只有两个变量，右边有三个元素。

## 三、字符串
字符串是一系列有顺序的字符。

例如：
```Python
s = "Python2026"
```
可以通过下标访问：
```Python
s[0]
s[1]
s[2]
```
字符串的下标从 ```0 ```开始。

例如：
```txt
位置：  0 1 2 3 4 5 ...
字符：  P y t h o n ...
```
### 1. 负数下标

字符串也支持负数下标：
```Python
s[-1]
```
表示最后一个字符。

例如：
```Python
s = "abcdef"

s[-1]  # f
s[-2]  # e
```
### 2. len()

```Python
len(s)
```
表示字符串中字符的数量。

例如：
```python
s = "abcdef"

len(s)
```
结果：
```txt
6
```
### 3. 遍历字符串

字符串可以直接使用 for 遍历：
```Python
s = "abc123"

for c in s:
    print(c)
```
每次循环得到一个字符。

可以理解为：
```txt
c = "a"
c = "b"
c = "c"
c = "1"
c = "2"
c = "3"
```
### 4. 字符串中的数字和整数不同

例如：
```Python
s = "abc123"

s[3]
```
得到：
```Python
"1"
```
这是字符串，不是整数。

如果需要转换成整数：
```Python
int(s[3])
```
得到：
```Python
1
```
### 5. isdigit()

```Python
c.isdigit()
```
用于判断一个字符是否为数字字符。

例如：
```Python
"7".isdigit()
```
结果：
```python
True
```
而：
```Python
"a".isdigit()
```
结果：
```python
False
```

## 四、计数器

用于计算一系列数据的总和。

基本结构：
```Python

for x in numbers:
    total += x
```
例如：
```Python
numbers = [10, 20, 30]
```

最终：
```txt

```

## 六、条件最大值

如果要求：

> 在满足某个条件的数字中寻找最大值

不能随便使用：
```Python
max_value = numbers[0]
```
因为```numbers[0]```可能根本不满足条件。

例如要求寻找```>= 6```的最大值：
```Python
numbers = [1, 2, 3, 8, 5]
```
如果：
```Python
max_value = numbers[0]
```
那么：
```txt
max_value = 1
```
但```1```根本不符合```>= 6```的条件。

**正确思路**
使用一个```found```状态：
```Python
found = False

for x in numbers:
    if x >= 6:
        if not found:
            max_value = x
            found = True
        elif x > max_value:
            max_value = x
```
最后：
```Python
if found:
    print(max_value)
else:
    print("没有符合条件的值")
```
核心思想：
```txt
第一次找到合法元素
        ↓
用它初始化答案
        ↓
后续遇到合法元素
        ↓
比较并更新答案
```

## 八、字典的频次统计

字典非常适合用来统计某个元素出现了多少次。

例如：
```Python
counts = {}
```
如果字符 c 第一次出现：
```Python
if c not in counts:
    counts[c] = 1
else:
    counts[c] += 1
```
例如字符串：
```txt
"112233"
```
最终：
```Python
{
    "1": 2,
    "2": 2,
    "3": 2
}
```

**使用 get() 简化频次统计**

也可以写成：
```Python
counts[c] = counts.get(c, 0) + 1
```
含义：
```Python
counts.get(c, 0)
```
如果```c```已经存在：

>返回```c```当前对应的 value。

如果不存在：

>返回```0```。

然后：
```Python
+ 1
```
完成计数。

这是竞赛中非常常见的字典计数写法。

## 九、字典 items()
```Python

```

例如：
```Python
counts = {
    "1": 2,
    "2": 3

for key, value in counts.
```

这里：


## 十、列表推导式

基本形式：
```Python
[表达式 for 变量 in 序列 if 条件]
```
例如：
```Python
[x for x in scores if x >= 60]
```
含义：

>遍历 scores 中的每一个元素，把满足 x >= 60 的元素放进一个新列表。

例如：
```Python
scores = [55, 72, 91, 48, 83]
```
执行：
```Python
[x for x in scores if x >= 60]
```
得到：
```Python
[72, 91, 83]
```

## 十一、时间复杂度

时间复杂度用于描述：

>当输入规模```n```增大时，程序执行次数如何增长。

### 1. O(n)

例如：
```Python
for x in numbers:
    print(x)
```
遍历一次长度为 n 的列表。
大约执行：
```
n 次
```
所以：
```
O(n)
```

### 2. 两个独立循环

例如：
```Python
for x in numbers:
    print(x)

for x in numbers:
    print(x)
```
执行次数：
```
n + n = 2n
```
忽略常数：
```
O(n)
```
所以：

>两个 for 不一定就是 O(n²)。

### 3. 嵌套循环

例如：
```Python
for i in numbers:
    for j in numbers:
        print(i, j)
```
执行次数：
```
n × n = n²
```
所以：
```
O(n²)
```

### 4. 固定次数的内层循环

例如：
```Python
for i in numbers:
    for j in range(10):
        print(i, j)
```
外层执行 n 次。

内层固定执行 10 次。

总执行次数：
```
n × 10 = 10n
```
忽略常数：
```
O(n)
```
因此：

**判断复杂度不能只看有几层```for```，还要看每一层循环次数是否随着```n```增长。**

## 十二、Day 02 核心算法思想

**1. 初始化 → 遍历 → 更新**

很多算法都可以抽象成：

```
初始化状态
    ↓
遍历数据
    ↓
根据当前元素更新状态
    ↓
遍历结束
    ↓
得到答案
```

**2. 第一次出现与后续出现**

处理数据时经常需要区分：

```
第一次遇到
    ↓
初始化

再次遇到
    ↓
  更新
```

例如字典频次统计：

```Python
if c not in counts:
    counts[c] = 1
else:
    counts[c] += 1
```

**3. 不要随意初始化答案**

如果题目要求：

>在满足条件的元素中寻找最大值。

不能直接假设：

```Python
max_value = numbers[0]
```

应该先找到一个真正符合条件的元素作为初始答案。

这也是 Day 01 “第二大不同数字”问题中遇到的重要思想。
